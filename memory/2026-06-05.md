# Daily Memory Log - 2026-06-05

## What was completed
- **Kept package name as `s3xc`**: Reverted the binary and package name from `s3cxd` to `s3xc` to prevent cache misses in CI target/registry caches.
- **Explicit Backend SigV4 Control**: Added support for `--backend-v4-auth` (boolean flag or `S3C_BACKEND_V4_AUTH` env var) to toggle Signature Version 4 authentication on/off for backend S3 calls.
- **Dynamic Frontend Credentials**: Rewrote `SigV4Verifier` in `src/server/s3_api.rs` and the auth middleware in `src/server/mod.rs` to support validating incoming requests against multiple access/secret key pairs configured via `--credentials` or `S3C_CREDENTIALS` (semicolon-separated `access:secret` format).
- **Dynamic Backend Signing**: Redesigned `ProxyClient` in `src/proxy/mod.rs` to vary signing methods (AWS SigV4 when credentials are provided and v4 auth is enabled, or Anonymous/unsigned if not). Upstream backend requests are signed exclusively with backend credentials, eliminating signature pass-through.
- **Dynamic Serialization**: Added support for both Path-style and Virtual-host-style URLs (`--backend-path-scheme true/false`) in `ProxyClient::build_url`, generating correct canonical URIs and `Host` headers for S3 compatibility.
- **Integration Tests Updated**: Expanded `tests/integration_test.sh` and CI environment to run the test suite using the new config options and test multiple frontend user credentials (`apple` and `blossom`).

## Key Decisions
- Standardized request serialization and signing logic into a single private helper `prepare_request` in `ProxyClient` to avoid code duplication across `head_object`, `get_object_range_stream`, `put_object_stream`, `delete_object`, `copy_object`, and `proxy_request`.
